While this is connected, Trinity controls this whole browser: every tab and window, the pages you are signed in to, and — when you ask her — the logins and cards kept in her vault.

Pair with Trinity

In Trinity, open Settings → Browser and press Show a pairing code. Type the code here. It works once, for ten minutes.

Right-click a page, a selection, a link or an image to put that on the board too. Everything else you just ask her for: tabs and windows, reading and changing pages, signing in, filling forms, saving files.

Connection

JavaScript on strict sites. Some sites block injected scripts. To let Trinity run JavaScript there, open this extension's details page and turn on Allow User Scripts. Styling changes work everywhere regardless.
